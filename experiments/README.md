# Experiments

This is my playground: code that **intentionally deviates from the book**.
The `chapter-XX/` folders stay close to what the book builds. Anything that wanders off goes here, such as:

- changing hyperparameters to see what happens
- testing small ideas and "what if…?" questions
- visualizations
- debugging snippets
- comparing implementations (mine vs. the book's, or two versions of mine)

## Conventions

- Name files after the chapter they relate to plus a short description, e.g. `ch03-<what-i-am-trying>.ipynb`.
- Start each experiment with a line or two: what I tried, what I expected, what actually happened.
- If an experiment teaches me something, add it to the chapter README or to [`notes/`](../notes/).
